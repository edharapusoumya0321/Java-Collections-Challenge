# Java Collections Challenge

## About the Project
This project demonstrates the use of Java Collections Framework through a simple menu-driven application.

## Technologies Used
- Java
- Eclipse IDE
- Java Collections Framework

## Collections Used

### 1. ArrayList — Book Management
- Add books
- View all books
- Search for a book
- Remove a book

### 2. HashMap — Student Management
- Add student details
- View student details
- Search students by ID

### 3. Queue — Customer Management
- Add customers to the queue
- Serve customers in order
- View the next customer
- Display all waiting customers

## How to Run
1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project as an existing Java project.
4. Open `Main.java`.
5. Run it as a Java Application.
6. Follow the menu displayed in the console.

## Learning Objectives
- Understand Java collections.
- Perform basic add, search, remove, and display operations.
- Understand FIFO (First In, First Out) queue behavior.
- Practice object-oriented Java programming.
